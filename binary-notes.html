Chapter 01

Counting in binary

In decimal we have 10 digits (0–9). In binary we only have 2, so we "carry" much sooner. Each position is worth double the one to its right: 1, 2, 4, 8, 16…

Bits & bytes

A single bit is one switch. Line up eight and you get a byte — enough to store one character. Stack bytes together and you get every file on your device.

Chapter 04

Data, files & compression

Data is any string of 1s and 0s — a photo, a song, this sentence. When data gets a name and a location on disk, it becomes a file.

Squeezing files smaller

LOSSLESS
Nothing is lost
Finds and removes repeated patterns. You get the exact original file back.
ZIP · PNG · FLAC
LOSSY
Some detail removed
Discards what humans barely notice. Files shrink dramatically but can't be perfectly restored.
JPEG · MP3 · MP4

Instead of storing every pixel, describe runs of the same color: "6 white, 4 black, 6 white" is far shorter than listing all 16 values.

Before: 16 values  ·  After: 6 values  ·  62% smaller
