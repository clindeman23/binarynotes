BINARY

The secret language every computer speaks. It only has two characters: 1 and 0. Everything else is built from those two choices.

1940s
Punch cards — a hole meant ON (1), no hole meant OFF (0).
ENIAC 1946

BUGS

0
STATE: OFF  |  VALUE: 0

A computer is millions of these. Each is ON (1) or OFF (0). That single choice, scaled to billions per second, powers everything.

DATA, FILES
& COMPRESSION

Data is any string of 1s and 0s. Give it a name and a location on disk — it becomes a file. Compression makes files smaller so they load faster and take less space.

LOSSLESS
Nothing removed
Finds repeated patterns, stores them shorter. Exact original is recoverable.
ZIP · PNG · FLAC
LOSSY
Detail removed
Drops what humans barely notice. Much smaller files, but can't be perfectly restored.
JPEG · MP3 · MP4

Run-length encoding: instead of storing 16 pixels one by one, store "6 white, 4 black, 6 white" — same picture, far fewer values.

BEFORE: 16 values  |  AFTER: 6 values  |  SAVED: 62%
